# Bomberman Casual

Браузерная многопользовательская игра в стилистике «казуального» Bomberman с комнатами до шести игроков.

## Стек

- **Frontend:** React + Vite + TypeScript, Zustand для клиентского состояния, Canvas 2D для визуализации поля.
- **Backend:** Node.js + TypeScript + Socket.IO, авторитарная симуляция игрового мира.

## Запуск локально

1. Установите зависимости фронтенда и сервера:
   ```bash
   cd client
   npm install
   cd ../server
   npm install
   ```
2. Запустите сервер: 
   ```bash
   npm run dev
   ```
   По умолчанию сервер слушает порт `4000`.
3. В другом терминале запустите клиент:
   ```bash
   cd ../client
   npm run dev
   ```
4. Откройте http://localhost:5173 и создайте комнату. Ссылка на комнату автоматически копируется и её можно отправить другим игрокам.

> При необходимости можно указать альтернативный адрес сервера через переменную окружения `VITE_SERVER_URL`.

## Предпросмотр / деплой в одном контейнере

Для быстрого предпросмотра в «боевом» режиме можно собрать и запустить единый Docker-образ, который
содержит и статический билд клиента, и авторитарный сервер:

```bash
docker build -t bomberman-app .
docker run --rm -p 4000:4000 bomberman-app
```

После запуска приложение будет доступно по адресу http://localhost:4000. Сервер автоматически раздаёт
собранный фронтенд и WebSocket-эндпоинт. Для кастомных доменов можно задать:

- `PORT` — порт, который слушает сервер (по умолчанию `4000`).
- `PUBLIC_URL` — внешний адрес, который будет использован в ссылках приглашения.
- `CLIENT_ORIGIN` — разрешённый Origin для CORS, если фронтенд хостится отдельно.
- `CLIENT_DIST_PATH` — путь к каталогу со статическим билдом клиента, если он размещён вне контейнера.

## Основные возможности

- Создание приватной комнаты и приглашение по коду/ссылке.
- До 6 игроков в лобби с отображением статуса готовности, пинга и роли хоста.
- Авторитарная серверная симуляция: движение, коллизии, бомбы, разрушение стен, бонусы и победа последнего выжившего.
- Поле 30×15 с фиксированными колоннами, случайно генерируемыми разрушаемыми стенами и выпадением бонусов (`speed`, `count`, `power`).
- HUD с таймером, индикаторами живых игроков, лентой событий и панелью перков.
- Чат лобби, тост об успешном копировании ссылки и экран итогов с таблицей результатов.

## Структура репозитория

- `client/` — фронтенд-приложение (Vite + React).
- `server/` — игровой сервер и REST API для создания комнат.
